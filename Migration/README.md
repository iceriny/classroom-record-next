 # 课堂采集迁移包

 这是一个为“技术栈迁徙”准备的可复原迁移包。它不保留原工程结构，而是按功能域组织：

 - `code/`：关键业务逻辑的 TS/TSX 源码（可直接复用或改写）。
 - `*.md`：分层级的解释性文档，包含业务流程、数据模型、存储与媒体策略等。
 - `09-assets.md`：资产清单与用途说明。

 ## 如何复原

 1. 先阅读 `00-app-overview.md` 与 `01-navigation.md`，建立整体业务流程与路由结构。
 2. 以 `02-data-model.md` 为数据模型基线，映射到新技术栈的数据结构。
 3. 依据 `03-storage-persistence.md` 与 `04-media-capture.md` 实现存储与媒体采集。
 4. 依次对照 `05-gallery-export.md` 与 `06-management.md` 复原功能页面。
 5. 按 `07-ui-theme.md` 迁移主题、组件与交互反馈。
 6. 按 `08-config.md` 落地运行时配置与权限。
 7. 依据 `09-assets.md` 整理资产文件并完成替换。

 ## 迁移建议

 - 迁移时优先保持“业务语义一致”，而非追求 UI 逐像素一致。
 - 数据模型、媒体命名策略、文件层级结构是可复原性的核心。
 - 原工程依赖 Expo / React Native，迁移到其他技术栈时请重点关注“权限、文件读写、媒体编解码与分享”。
